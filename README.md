# Valeric Acid and Therapy Intensification in IBD

This repository contains the R scripts used for statistical analyses and figure generation in the manuscript:

**"Low Faecal Valeric Acid at Baseline Is Associated with Higher Future Risk of Therapy Intensification in Inflammatory Bowel Disease"**

## Overview

This study investigates the association between baseline faecal valeric acid levels and future therapy intensification in patients with inflammatory bowel disease (IBD), using clinical follow-up, faecal metabolomics, and gut metagenomic data from the 1000IBD cohort.

## Repository Contents

The R scripts cover:

- Survival analyses and Cox regression models
- Kaplan–Meier curves and forest plots
- Associations between gut microbiome features, short-chain fatty acids (SCFAs), and clinical outcomes
- Generation of manuscript figures and heatmaps

## Data Availability

The analyses are based on data from the 1000IBD cohort. Data availability and access information are provided in the manuscript.
